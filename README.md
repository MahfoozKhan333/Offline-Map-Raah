# Raah – Offline Maps for Dubai

Raah is an offline-first web app for Dubai. Search places in English or Arabic, save favourites, and view maps with GPS.

Download map areas and road data once to get offline driving directions with turn-by-turn navigation, rerouting, and ETA.

## Features

- English and Arabic place search
- User sign-in and favourites
- GPS-enabled maps
- Offline map and road data
- Turn-by-turn driving directions
- Automatic rerouting and ETA
- Installable on mobile devices
- Easy to self-host
